# Roadmap
This software is very much a proof-of-concept and not ready for general use. It is developed in spare time and with a certain personal goal of a port to Windows PE in mind, so these features will cater primarily to this first and foremost.

### Planned Features
These features are ones that will be supported come general availabilty.
- [ ] Audio support
- [ ] Folder based theme support + ZIP theme support
- [ ] Use of PS1 TIM image files
- [ ] File-based mapped input support
- [ ] GUI based configuraiton tool for mapped inputs
- [ ] Limited configurable menu structure
- [ ] Backporting of non-Windows features to 573in1
- [ ] Use of PS1 VAG sample formats

### Potential Future Features
These features are considered as potential options for future, but are not being worked on in the immediate timeframe. 
* Linux/MacOS support (using modular codebase)
* Direct2D/OpenGL support (not on Windows PE)
* JSON/Lua support for dynamic menus

The following should be seen as "might be interested in doing" but without any gaurentee of happening.
* Application support using a modular nature (think games/emulators where the menu is the frontend)
* iOS/Android support

### Will not add
The following points are ones where it will not be added to the codebase for various reasons.
* Items which might infringe copyright.
